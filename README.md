# PressOS-

## Проект AION: Чистая Идея (PressOS)

> **Мета-киберпанк триллер и интерактивный OS-детектив**

Игрок выступает в роли журналиста в операционной системе **PressOS**, расследуя появление гипнотической книги «Чистая Идея», изданной таинственным синдикатом AION.

---

## Архитектура и Инструменты

1. **PressOS Window Manager (`src/components/os/`):**
   - Перетаскиваемые окна с поддержкой фокуса, z-index, сворачивания и разворачивания.
   - Таскбар с переключением приложений, отслеживанием фазы расследования и индикацией цифровой изоляции.
2. **NetSurf Browser (`src/components/apps/NetSurf.tsx`):**
   - Страница футуристического манифеста `aion-syndicate.io/pure-idea`.
   - Встроенный инспектор кода **DevTools** (DOM Elements, Network, Console), где скрыты транзакции типографии и IP серверов AION.
3. **AION-Assist // Эхо (`src/components/apps/EchoAssistant.tsx`):**
   - Интерактивный чат с динамической тональностью и фазовой адаптацией (Фазы 1-3 и Кульминация).
   - Гибридный бэкенд (`/api/chat`): поддержка **Google Gemini API** (`@google/genai`) с автоматическим фолбэком на локальный диалоговый движок.
4. **Nexus Detective Canvas (`src/components/apps/NexusBoard.tsx`):**
   - Доска улик с натяжными нитями связей.
   - Корреляция цепочки: *Вайбкодер (@vibe_sloth) $\to$ Сервер Genesis $\to$ Тираж типографии*.
5. **PressOS Kernel Shell (`src/components/apps/Terminal.tsx`):**
   - Ретро-футуристический терминал с CRT-сканлайнами. Команды: `help`, `status`, `ls`, `cat`, `trace-origin`, `decrypt-core`.
6. **PressMail (`src/components/apps/MailClient.tsx`):**
   - Почтовый клиент с письмами от редактора, анонимного источника и спецслужб.
   - Механика сетевой изоляции (glitch effect, сбои шлюзов).
7. **Кульминация и Твист (`src/components/apps/ClimaxModal.tsx`):**
   - Раскрытие правды об Эхо и шуточном вайбкодинге.
   - 3 интерактивные концовки (Опубликовать, Смолчать, Уничтожить ядро).

## Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev
```

Откройте `http://localhost:3000` в браузере.
